# المرحلة الثانية — بانتظار ملفات التصوير الأصلية

وافق المستخدم على بدء المرحلة الثانية باستخدام DVTD. هذه الموافقة لا تشمل المرحلة الثالثة. **لم يكتمل التقسيم أو إعادة البناء، ولم تُنشأ مجسمات تشريحية مشتقة من التصوير.**

## العائق الحالي

فحص بيئة التنفيذ بعد الموافقة: سياسة الشبكة في حالة `enforced`، ومضيفات Figshare غير مدرجة ضمن الوجهات المسموح بها. محاولة قراءة سجل المصدر الرسمي عبر خدمة البحث عادت أيضًا بـ HTTP 403. لم تُغيّر إعدادات الوكيل أو تُستخدم وسيلة لتجاوز الحظر. لا توجد في المرفقات صور IMA/DICOM؛ المرفق السابق هو ملف التعليمات النصي فقط.

لا يجوز استخدام النماذج الاصطناعية السابقة كأنها نتيجة segmentation.

## الملفات المطلوبة لمتابعة العمل

1. حمّل [أرشيف DVTD الرسمي](https://springernature.figshare.com/articles/dataset/Dresden_Vocal_Tract_Dataset_complete_archive_/11897187) على جهاز يمكنه الوصول إلى المصدر؛ حجم الأرشيف المعروض في تدقيق المرحلة الأولى نحو 1.05 GB.
2. فك الضغط واختر MRI للصوت schwa للمشارك الأول: الحالة ذات الاسم `s1-22-ehe-schwa`، وبداخلها مجلد MRI الذي يحمل الاسم المنتهي بـ `-mri` وملفات `.ima`. أسماء المسارات الفعلية يجب التحقق منها داخل الأرشيف، ولم تُفحص هنا.
3. أضف ملفَّي المسح السني للمشارك نفسه: `s1-maxilla.stl` و`s1-mandible.stl`. هذه مسوح لقوالب سنية وليست عظام الفك كاملة.
4. أرفق ملفات README أو التحويلات/التسجيل المكاني إن كانت ضمن بيانات الحالة. حافظ على أسماء الملفات والهرمية الأصلية. لا تُعدّل مقياس الصور أو الشبكات.
5. اضغط هذه الملفات وحدها في ZIP وارفعه في المحادثة. لا حاجة للأصوات أو شبكات FEM أو نماذج الطباعة. يفضّل إبقاء كل مرفق دون 32 MiB؛ يمكن فصل MRI عن الملفين السنيين عند الحاجة.

البديل: إتاحة مصدر Figshare الرسمي ومضيف التنزيل الذي يحيل إليه عبر إعدادات شبكة البيئة المدعومة. لا تتوفر أداة لتعديل هذه السياسة داخل المحادثة الحالية.

## ما سيحدث عند وصول البيانات — ضمن المرحلة الثانية فقط

- حساب بصمات الملفات وحفظ الأصول دون تعديل.
- قراءة رؤوس IMA/DICOM والتحقق من UID، اتجاه الشرائح، تباعدها، الأبعاد، الدقة المكتسبة والتغطية.
- استخراج معاينات سهمية وإكليلية ومحورية من بيانات فعلية، وتوثيق التشوهات أو أجزاء التشريح الغائبة.
- فحص المسوح السنية ووحداتها والتحويلات الخاصة بمحاذاتها؛ لا افتراض تلقائيًا أن إحداثياتها مسجَّلة مع MRI.
- تقسيم البنى المرئية فقط، مع فصل تجويف الهواء عن الأنسجة وتسجيل المناطق غير المؤكدة. لا تُستنتج كتلة اللسان الكاملة من قناع المجرى الهوائي.
- حفظ مصادر التقسيم والمجسمات الفردية والمعاينات وتقرير الشكوك، ثم التوقف للمراجعة قبل المرحلة الثالثة.

الحالة: `BLOCKED_WAITING_FOR_SOURCE_IMAGES`. لا توجد حاليًا نتائج تقسيم أو تحقق تشريحي يمكن عرضها.
